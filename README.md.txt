# 💛 AmarilloBank - Proyecto Integrador

Sistema bancario simulado. Gestión de clientes, cuentas, tarjetas, CDT, préstamos y movimientos.

### 📁 Estructura
- `AmarilloBank_bakend/` - Lógica del banco
- `amarillobank_frontend/` - Interfaz login
- `docs/` - Documentación UML, casos de uso e historias de usuario

### 📚 Documentación
Toda la documentación está en `/docs`:
- Casos de Uso: `docs/casos_de_uso/`
- Diagrama UML: `docs/diagrama_uml/`
- Historias de Usuario: `docs/historias_de_usuario/`
